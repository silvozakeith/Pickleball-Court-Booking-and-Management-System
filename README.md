# CPE 010 Data Structures & Algorithms - Group Project

## 📌 Project Description
This repository contains a C++ Data Structures and Algorithms project developed using the **Waterfall SDLC model**. The project focuses on core DSA topics, primarily featuring **Binary Search Trees (BST)** alongside Arrays, Linked Lists, Stacks, Queues, Searching, and Sorting algorithms to manage records efficiently.

### Proposed Systems Covered:
1. **Pickleball Court Booking & Management System**
   - Manages court reservations, schedules, waitlists, and payment tracking while preventing double-bookings.
